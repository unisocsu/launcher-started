# KosherLauncher

Starter project for a Java Android launcher designed for keypad / D-pad devices.

## Target

- Java
- Minimum Android API 19
- Launcher activity
- D-pad / keypad navigation foundation
- Ready for GitHub + Gradle Wrapper

## Planned modules

- App launcher
- File search
- File preview
- Widgets via AppWidgetHost
- D-pad / numeric-key navigation
- Home-screen grid
- Persistent layout
